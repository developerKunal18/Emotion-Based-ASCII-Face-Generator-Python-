# Emotion-Based-ASCII-Face-Generator-Python-
A Python program that generates ASCII art faces based on the user’s selected emotion. This is not just drawing static faces — the code procedurally generates expressions like:  😀 Happy  😢 Sad  😡 Angry  🤯 Shocked  😏 Smirking  😴 Sleepy  🤖 Robot mode  Each face is built from randomized patterns and templates.
