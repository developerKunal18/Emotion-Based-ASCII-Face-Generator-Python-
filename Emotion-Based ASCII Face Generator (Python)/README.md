# 🎭 ASCII Emotion Face Generator

## 💡 Overview
The **ASCII Emotion Face Generator** is a fun Python project that creates  
clean, well-aligned ASCII faces based on the emotion selected by the user.

Each face is:
- boxed inside a neat frame  
- properly aligned (eyes, brows, mouth, nose)  
- emotion-specific  
- slightly randomized for variety  
- easy to recognize in any terminal  

This makes the output visually clear, readable, and fun.

---

## 🎯 Features

### ✔ Multiple Emotions
Choose from:
- 😀 Happy  
- 😢 Sad  
- 😡 Angry  
- 😮 Shock  
- 😏 Smirk  
- 😴 Sleepy  
- 🤖 Robot  

### ✔ Clean ASCII Art
Faces are drawn inside a **fixed-width ASCII box**, ensuring:
- perfect alignment  
- consistent appearance  
- cross-terminal readability  

### ✔ Random Variations
Each emotion generates slightly different:
- eyebrows  
- eyes  
- mouth  
- nose  

So no two faces look the same!
